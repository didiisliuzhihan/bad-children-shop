# V5.6.5 — Simpler password and quiet resident visits

- Registration, login and recovery forms/validators accept passwords with at least 6 Unicode characters. No required character mixture. Existing passwords are unchanged. Keep the existing 72-byte backend limit; never trim, normalize or truncate passwords. Frontend and Edge checks match.
- Tapping a 3D resident while visiting the nest no longer opens its toy/card detail. The scene exits before raycasting or claiming a visit gesture. Arrangement selection/dragging and independent story bubbles remain available. The card pack and task entries in the resident list remain available.
- Update visiting hints so they no longer invite tapping the resident for details. No art, lighting, audio, collection or story changes.

## Scope and remaining issues

This is not the overall performance release. Card display still waits for image/font composition; account keep still waits for a full reload; private-media signing is still sequential. Those paths were inspected and a staged responsiveness/reliability plan was proposed, not implemented here.

The phone arrangement scroll issue reported after V5.6.4 is still open. Native-touch unit tests and a mouse in a narrow viewport do not establish physical iPhone/WebView correctness. The proposed floor-only interaction-layer redesign is not part of this release.

## Validation scope

Regression tests cover 5/6-character boundaries, multibyte limits, rendered registration/login/recovery forms, unchanged account security guards, visit-mode no-op taps, arrangement pointer capture/release and story bubble expansion. No existing player's password or collection is modified for these tests.

- TypeScript, production build/single-file verification and 152 automated tests passed.
- Live Edge check: a 5-character registration is rejected; a new empty QA account can register and log in with a 6-digit password, read its own empty collection, then sign out both QA sessions. No password reset or collection operation was run against an existing player.
