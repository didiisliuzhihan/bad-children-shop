# V5.6 · 住下来

This release keeps the gashapon machine as the first screen. Guests can still draw without registering.

## Included

- Site-only name/password accounts, one-time recovery keys, cloud collections, task progress, saved room layouts and private postcard drafts.
- Explicit, append-only import of this browser's old guest collection. Records are not deleted, duplicates are not counted twice, and another account's records cannot be claimed. Old browser-only task timestamps are not imported as server unlocks.
- Separate toy and postcard shelves; one resident of each toy kind in the room, regardless of duplicate cards.
- Furnished, borderless room; day/night lighting; room-scoped recorded fireplace ambience, including arrangement mode; passive mood bubbles and conditional little scenes.
- Fresh visible room events can capture a 960×960 character close-up and save a story into the owner's private capsule pool. Collected stories have no player stamp and are never public.
- Player postcards remain private drafts. Submission to a public/shared pool is explicitly not open.
- Reveal controls no longer sit underneath the decorative portrait glow. Model failure has an image fallback; hidden room rendering pauses and shared model resources survive view changes.

## Verification

- TypeScript, production build and 128 automated tests passed.
- 50 real account API checks passed: registration/login/recovery, append-safe import, ownership isolation, stale-write rejection, private media, server-side quest timing and idempotent capsule collection.
- Production-origin CORS verified against the deployed account function.
- A real legacy anonymous identity with 1,203 records migrated in batches; repeated import added zero, a fresh login restored all IDs, and the original guest records remained intact.
- A separate QA account completed the real task wait, placed two residents, generated a soup story with a real close-up, drew it through the machine and collected it. Coordinate-based reveal clicks passed in wide and narrow layouts.
- After logout/login, the two toy cards, collected photo story and both saved room placements were restored in the browser. No browser errors or warnings were reported during this check.

## Boundaries

- Previously generated text-only stories and offline return summaries are retained. A closed browser cannot photograph a past scene; no fabricated historical image is attached.
- Desktop narrow-layout checks are not an iOS/Android hardware certification. Audio texture/comfort still benefits from listening on the intended devices.
- Supabase's leaked-password-protection advisory remains an account-security follow-up. Authentication, session revocation, ownership checks and rate limits remain enforced.
- The three new public visual/audio assets ship with the same Pages commit as the HTML. Private media and credentials are not included in the repository.
